毕设题目：Go 应用池化内存管理与优化
基本内容和要求
内容
Go 凭借轻量级协程和自动垃圾回收（GC），已成为云原生、微服务等领域的首选语言。然而 Go 的 GC 与大对象堆分配存在固有开销，在"高吞吐、长生命周期"的常驻数据场景下，堆内存容易出现峰值不回落、结构体与索引数组只增不减等内存滞留问题，推高进程常驻内存，成为服务成本的瓶颈。基于 slab/arena 思想的池化内存管理被广泛用于缓解这些问题，但现有实现在回收粒度、容量伸缩、池生命周期等环节仍有可观的优化空间。
本选题聚焦 Go 应用池化内存管理的内存滞留与回收不及时问题，分层剖析各环节（对象→span→arena→顶层池）的分配与释放策略，结合 Go 运行时 GC 机制（触发点、存活堆、以及新提出的 runtime.freegc 提前回收机制）进行量化分析，设计并实现一套内存滞留度量、定位与优化方案，例如按需缩容结构体与索引数组、优化回收粒度、改进池生命周期管理、协同调优 GC 参数，最终形成一个可测量、可复现的池化内存优化框架，降低 Go 应用的内存占用与 GC 开销。

要求
熟练掌握 Go 语言，了解 C/C++ 或 Python 者优先。
了解操作系统内存管理、堆分配机制与 Go 运行时（GC、内存分配器）等基础知识。
能阅读分析开源池化/内存分配代码，具备性能剖析（pprof、runtime.MemStats、GC trace）与基准测试能力。
能对优化方案进行定量评估（内存占用、GC 频率、时延对比）。
